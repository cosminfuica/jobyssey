# Features talk through entry points; outside services plug in as adapters

A feature reaches another feature only through its entry points and never queries another feature's tables; foreign keys through `schema.ts` are the one exception (ADR 0013). Each outside service (LLM, login, email, file storage) sits behind a small interface that Jobyssey owns, and the composition root (`apps/api`) passes the implementation (adapter) in at startup. Each such interface is one package; the adapters that ship with Jobyssey live as one file each inside it (the pattern `auth`, `llm` and `job-sources` follow), and a composition root may pass in an adapter from any other package. Features call each other directly; in-process events are added only when the first cross-feature side effect needs them.
