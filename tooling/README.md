# tooling

Shared configuration packages: `@jobyssey/typescript-config` (compiler settings), `@jobyssey/oxlint-config` (lint rules) and `@jobyssey/vitest-config` (test projects). A package consumes them by listing `@jobyssey/typescript-config` as a devDependency (`workspace:*`) and extending `@jobyssey/typescript-config/base.json` (or `web.json`) from its own `tsconfig.json`, and, when it has tests, by listing `@jobyssey/vitest-config` and `vitest` and exporting `createVitestConfig()` from its `vitest.config.ts`, so `extends` and the Vitest import resolve from the package's own `node_modules` in any workspace that includes it; lint rules apply through the root `oxlint.config.ts`. `types: ["node"]` in the base resolves through the root's `@types/node`, an implicit root dependency. `tooling/*` holds no runtime code, and the config packages have no scripts: they are typechecked and linted through the root `typecheck:root` and `lint:root` scripts.
