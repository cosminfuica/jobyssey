# Security policy

## Supported versions

Only the latest release gets security fixes. Upgrade before you report, if you can.

## Reporting a vulnerability

Report it privately through GitHub Security Advisories: https://github.com/cosminfuica/jobyssey/security/advisories/new

Don't open a public issue, discussion or pull request for a vulnerability.

There's no bug bounty.

## What to expect

- The maintainer acknowledges your report within 7 days.
- You get updates in the advisory while the fix is worked on.
- Once a fix ships, the advisory is published and you're credited unless you ask not to be.

## Reports written with AI

Every report must include a reproduction: the steps, the version and the output you saw. Fabricated or unverified reports, including AI-generated ones nobody ran, lead to a ban.
