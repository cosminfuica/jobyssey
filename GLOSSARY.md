# Jobyssey

Jobyssey helps people find a job.

## Language

**Job Seeker**:
A person looking for a job, whether currently employed or unemployed.
_Avoid_: Employee (implies current employment)

**Job Posting**:
A specific opening an employer advertises, found through a Job Source.
_Avoid_: Job, listing, ad, vacancy

**Job Source**:
A place where Jobyssey finds Job Postings: an employer's hiring system, a national job bank, or a job board.
_Avoid_: Portal, board, provider

### AI work

**LLM Provider**:
The service that runs the language model behind Jobyssey: a vendor reached with an API key, or a model running on the Job Seeker's own hardware.
_Avoid_: AI vendor

**Harness**:
An AI agent program installed on the Job Seeker's computer, such as Claude Code, Codex, OpenCode or Pi, that Jobyssey hands a Mode to.
_Avoid_: Agent, CLI, LLM Provider

**Mode**:
A defined piece of AI work Jobyssey performs, with fixed instructions, allowed tools and result shape, such as evaluating a Job Posting.
_Avoid_: Skill (means a Job Seeker's abilities), playbook, prompt

**Run**:
One execution of a Mode for a Job Seeker.
_Avoid_: Job, task, execution
